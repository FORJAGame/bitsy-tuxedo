# Hacks

*Stub in upstream Bitsy's docs too — not expanded here yet.*

"Hacks" refers to modifying a game's exported HTML/JS directly to do things the editor UI doesn't expose — custom engine behavior, injected scripts, etc. Since Bitsy Tuxedo doesn't change the underlying engine (`editor/script/engine/`), any hack written against stock Bitsy/Bitsy Color applies unmodified here.

See the [System API](../system.md) for the documented low-level hooks the engine exposes.
