# Glossary

- **Avatar** — the object you control when playing the game.
- **Sprite** — an object you can "talk" to when playing the game; each one placed in the world is its own instance.
- **Tile** — decoration; not interactive, but can be marked as a wall.
- **Item** — an object that can be "picked up" and tracked in the [inventory](tools/inventory.md).
- **Drawing** — the umbrella term for avatars, sprites, tiles, or items collectively — anything made in the [Paint](tools/paint.md) tool.
- **Room** — a 16×16-tile space the avatar can walk around in.
- **Palette** — the (3–64 color) set of colors a room's artwork draws from. See [Colors](tools/color.md).
- **Exit / Ending** — a connection between locations, or a location that ends the game. See [Exits & Endings](tools/exitsandendings.md).
- **Tune** — a composed, looping piece of chiptune background music. See [Music](tools/music.md#tune).
- **Blip** — a short synthesized sound effect. See [Music](tools/music.md#blip).
- **Imported audio** *(Bitsy Tuxedo)* — an external sound file (mp3/wav/ogg/flac/aac/m4a) brought in through the [Music tool's Audio tab](tools/music.md#audio-bitsy-tuxedo), usable as room music in the editor's Play preview only — it is not included in exported games.
