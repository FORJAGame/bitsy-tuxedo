# Find

*Unchanged from stock Bitsy.*

The find tool is a unified search/browser over everything you've created — drawings, rooms, palettes, dialogs, tunes, blips, and more.

- **Search field** — filters results by name as you type.
- **Category tabs** — narrow results to one kind of asset at a time (e.g. click "colors" to see only palettes).
- **Results list** — every matching item, filtered by both the search text and the selected tab. Anything currently open/selected in its owning tool is highlighted in blue.

Click any result to open it directly in its tool — e.g. clicking a sprite opens the paint tool with that sprite selected.

Most other panels have their own "find" shortcut button that opens this tool pre-filtered to their category (rooms, dialogs, palettes, tunes/blips, etc.).
