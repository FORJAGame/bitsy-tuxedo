# Hacks

*Também é um esboço nos docs originais do Bitsy — ainda não expandido aqui.*

"Hacks" se refere a modificar diretamente o HTML/JS exportado de um jogo pra fazer coisas que a interface do editor não expõe — comportamento customizado da engine, scripts injetados, etc. Como o Bitsy Tuxedo não muda a engine subjacente (`editor/script/engine/`), qualquer hack escrito pro Bitsy/Bitsy Color original funciona aqui sem modificações.

Veja a [System API](../system.md) pros hooks de baixo nível documentados que a engine expõe.
