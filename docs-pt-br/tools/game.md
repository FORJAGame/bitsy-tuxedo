# Game (Jogo)

*Majoritariamente inalterado em relação ao Bitsy original — os controles de tema do editor que antes ficavam em Settings agora têm seu próprio painel [Theme](theme.md).*

O painel Game é a central de controle do projeto: salvar/carregar, configurações do projeto inteiro, e acesso aos dados brutos.

## Save (Salvar)

- **Export (exportar)** — baixe seu jogo como um único arquivo HTML autocontido e jogável.
- **Import (importar)** — carregue um arquivo de jogo exportado/salvo anteriormente de volta no editor pra continuar trabalhando nele.
- **New project (novo projeto)** — comece do zero com um jogo em branco.

## Settings (Configurações)

- **Preferências do editor** — conveniências só do editor (por exemplo, visibilidade da grade na ferramenta de pintura).
- **Configurações da engine** — opções de comportamento do jogo inteiro.
- **Configurações de exportação/HTML** — a cor de página e o dimensionamento do arquivo exportado (tamanho fixo em pixels vs. preencher a janela do navegador).
- **Language (idioma)** — troque o idioma da interface do próprio editor. O Bitsy Tuxedo adiciona **Português Brasileiro (`pt-BR`)** como sua própria entrada, distinta da tradução de Português Europeu (`pt`) já existente — escolha a que combina com seu dialeto.
- **Font (fonte)** — escolha/importe a fonte com que o texto de diálogo do seu jogo é renderizado.

## Data (Dados)

Mostra os dados de salvamento subjacentes do jogo como texto puro — o mesmo formato que você obteria do Export, menos o wrapper de HTML. Útil pra copiar e colar um projeto entre máquinas sem baixar um arquivo, editar em lote com busca-e-substituição, ou só ver exatamente o que uma mudança fez por baixo dos panos.
