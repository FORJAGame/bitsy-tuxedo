# Theme (Tema)

*Novo no Bitsy Tuxedo — o Bitsy original não tem personalização de tema do editor.*

O painel Theme controla a aparência do *próprio editor*. Ele não tem efeito no seu jogo, suas paletas, ou qualquer coisa que você exporta — é puramente uma preferência pessoal, lembrada por navegador (`localStorage`), não salva no arquivo do seu jogo.

- **Dark mode (modo escuro)** — alterna toda a interface do editor (painéis, botões, fundos) entre claro e escuro. O rótulo do botão muda pra "light mode" assim que o modo escuro está ativado, pra que você saiba pra qual lado ele vai virar em seguida.
- **Editing tint (tom de edição)** — a cor de destaque usada por toda a interface do editor enquanto você está no modo de edição.
- **Playing tint (tom de jogo)** — uma cor de destaque separada usada enquanto você está no modo de teste de jogo, pra que fique visualmente óbvio de relance se você está editando ou testando.

Ambos os tons funcionam escolhendo um matiz a partir da cor que você escolher e aplicando ele por todos os tons de destaque claro/escuro já existentes da interface — então você está recolorindo o destaque, não definindo um valor hex exato pra cada elemento.
